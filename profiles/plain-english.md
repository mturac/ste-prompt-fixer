# plain profile — public plain language

Looser sibling of ste80. No fixed vocabulary; the goal is readability, not machine-parsability.

1. Max 20 words per sentence.
2. Everyday words over jargon. If jargon is needed, define it in the same sentence.
3. Active voice.
4. Second person address allowed ("you") — service-manual tone is not required.
5. Contractions allowed.
6. One idea per sentence, one topic per paragraph.

Use for: public websites, onboarding docs, changelog notes, non-expert readers.
Skip for: safety procedures, API reference, translation pipelines — use ste80 or cte there.
